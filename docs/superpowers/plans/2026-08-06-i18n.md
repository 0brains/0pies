# 0pi.es Internationalization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Full-site support for 14 major languages (es pt fr de it pl tr ru ar hi zh ja ko vi) via inlined UI dictionaries, lazy per-lab card overlays, and AI-handoff language hints — keeping English pages at today's weight and `file://` fully working.

**Architecture:** UI strings move behind a ~20-line `t()` helper reading an `I18N` bundle stamped into every page by `build_lab.py`. Card content is translated in checked-in JSON mirroring `data/decks/`, compiled per-lab into `gamification/i18n/<labid>.<lang>.json`, fetched only when a language is picked, and merged by re-parsing the pristine inlined deck JSON and patching it by item id. All validation is build-blocking.

**Tech Stack:** Vanilla JS (no library), Python 3 stdlib (`build_lab.py`), headless Chrome over CDP (`verify_*.mjs` pattern).

**Spec:** `docs/superpowers/specs/2026-08-06-i18n-design.md`

## Global Constraints

- Answer strings, `options`, zone `key`/`name`, citations, service/statute names are NEVER translated.
- English page weight unchanged except the UI dictionary bundle (~80–120KB total across locales).
- `file://` and offline: overlay fetch failure silently falls back to English cards; UI still translates.
- All locale/overlay gaps are build-blocking errors for languages listed in `data/i18n/languages.json`.
- `gamification/*.html` is generated — edit templates and data, never output. EXCEPTION: `gamification/index.html` is hand-edited (documented README caveat); edit it directly.
- egy/kli stay landing-page-only, partial-coverage-allowed, font-swap behavior identical.
- No new font downloads. No runtime network calls except the lazy overlay fetch.
- Every string in `data/` passes the existing `_reject_markup` check (free, via `load_json`).
- Commit after every task with `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`.

- [ ] **Step 4: Write the failing check — build must reject a locale with missing/extra keys or drifted placeholders**

Add to `tools/build_lab.py` (below `load_json`):

```python
I18N_DIR = REPO / "data" / "i18n"
_PLACEHOLDER = re.compile(r"\{(\w+)\}")

def load_i18n():
    """Load languages.json + every listed UI locale + labs translations.

    Strictness rule: a language listed in languages.json is a shipped
    language. Its ui/<code>.json must exist and carry exactly en.json's key
    set, with identical {placeholder} sets per key. labs/<code>.json (absent
    for en — the manifests are the English source) must cover exactly every
    <labid>.<gameid>.title/.blurb. Returns (languages, ui, labs_tr, errors).
    """
    errors: list[str] = []
    langs = load_json(I18N_DIR / "languages.json")["langs"]
    codes = [l["code"] for l in langs]
    if codes[0] != "en":
        errors.append("languages.json: 'en' must be first")
    if len(set(codes)) != len(codes):
        errors.append("languages.json: duplicate language codes")
    ui: dict[str, dict] = {}
    for code in codes:
        ui[code] = load_json(I18N_DIR / "ui" / f"{code}.json")
    en_keys = set(ui["en"])
    for code in codes[1:]:
        missing = en_keys - set(ui[code])
        extra = set(ui[code]) - en_keys
        if missing:
            errors.append(f"ui/{code}.json: missing keys {sorted(missing)[:8]}"
                          + (f" (+{len(missing)-8} more)" if len(missing) > 8 else ""))
        if extra:
            errors.append(f"ui/{code}.json: unknown keys {sorted(extra)[:8]}")
        for k in en_keys & set(ui[code]):
            if set(_PLACEHOLDER.findall(ui["en"][k])) != set(_PLACEHOLDER.findall(ui[code][k])):
                errors.append(f"ui/{code}.json: '{k}' placeholder mismatch vs en")
    expected = set()
    for path in sorted(LABS.glob("*.json")):
        m = json.loads(path.read_text(encoding="utf-8"))
        for g in m.get("games", []):
            expected.add(f"{m['id']}.{g['id']}.title")
            expected.add(f"{m['id']}.{g['id']}.blurb")
    labs_tr: dict[str, dict] = {}
    for code in codes[1:]:
        p = I18N_DIR / "labs" / f"{code}.json"
        if not p.exists():
            errors.append(f"labs/{code}.json: missing (must cover every game title/blurb)")
            continue
        labs_tr[code] = load_json(p)
        missing = expected - set(labs_tr[code])
        if missing:
            errors.append(f"labs/{code}.json: missing {sorted(missing)[:8]}"
                          + (f" (+{len(missing)-8} more)" if len(missing) > 8 else ""))
    return langs, ui, labs_tr, errors

def i18n_payload(manifest, langs, ui, labs_tr):
    """The bundle stamped into one lab page: all UI locales, this lab's
    game-title translations only."""
    prefix = manifest["id"] + "."
    return {
        "meta": {l["code"]: {"name": l["name"], "dir": l["dir"], "cards": l["cards"]}
                 for l in langs},
        "ui": ui,
        "labs": {code: {k: v for k, v in tr.items() if k.startswith(prefix)}
                 for code, tr in labs_tr.items()},
    }
```

```js
/* ------------------------------------------------------------------ i18n */
const I18N = JSON.parse(document.getElementById("i18n").textContent);
const LANG_KEY = "0pies.lang";
function pickLang(){
  try{ const s = localStorage.getItem(LANG_KEY); if(s && I18N.meta[s]) return s; }catch(e){}
  const nav = (navigator.language || "en").toLowerCase().split("-")[0];
  return I18N.meta[nav] ? nav : "en";
}
let lang = pickLang();
function t(key, vars){
  const d = I18N.ui[lang] || {};
  let s = d[key] != null ? d[key] : I18N.ui.en[key];
  if(s == null){ console.error("i18n: missing key " + key); return key; }
  if(vars) for(const k in vars) s = s.split("{"+k+"}").join(vars[k]);
  return s;
}
const tn = (key, n) => t(key + (n === 1 ? "_one" : "_other"), {n});
function tGame(gameId, field, fallback){
  const v = (I18N.labs[lang] || {})[LAB.id + "." + gameId + "." + field];
  return v != null ? v : fallback;
}
/* Card-content overlay: flat {itemId | "zone:<key>": {dottedPath: text}}.
   Applied by re-parsing the pristine inlined deck JSON and patching it in
   place — one seam that covers every adapter, corpora included, at zero
   per-render cost. English restore = re-parse without patching. */
let OVERLAY = {};
const overlayCache = {};
async function loadOverlay(code){
  OVERLAY = {};
  if(code === "en" || !(I18N.meta[code] || {}).cards) return;
  if(overlayCache[code]){ OVERLAY = overlayCache[code]; return; }
  try{
    const r = await fetch("i18n/" + encodeURIComponent(LAB.id) + "." + code + ".json");
    if(!r.ok) throw new Error("HTTP " + r.status);
    OVERLAY = overlayCache[code] = await r.json();
  }catch(e){ /* file:// or offline — English cards, translated UI */ }
}
function patchTree(node){
  if(Array.isArray(node)){ node.forEach(patchTree); return; }
  if(!node || typeof node !== "object") return;
  const oKey = node.id != null ? String(node.id)
             : (node.key != null && node.def != null ? "zone:" + node.key : null);
  const o = oKey != null ? OVERLAY[oKey] : null;
  if(o) for(const path in o){
    const parts = path.split("."); let tgt = node;
    for(let i = 0; i < parts.length - 1 && tgt; i++) tgt = tgt[parts[i]];
    const leaf = parts[parts.length - 1];
    if(tgt && typeof tgt[leaf] === "string") tgt[leaf] = o[path];
  }
  for(const k in node) patchTree(node[k]);
}
function relocalizeDecks(){
  DECKS = JSON.parse(document.getElementById("lab-decks").textContent);
  if(Object.keys(OVERLAY).length) patchTree(DECKS);
}
function applyStatic(){
  document.querySelectorAll("[data-i18n]").forEach(n => n.textContent = t(n.dataset.i18n));
  document.querySelectorAll("[data-i18n-attrs]").forEach(n =>
    n.dataset.i18nAttrs.split(";").forEach(pair => {
      const i = pair.indexOf(":");
      n.setAttribute(pair.slice(0, i), t(pair.slice(i + 1)));
    }));
}
async function setLang(code){
  if(!I18N.meta[code]) return;
  lang = code;
  try{ localStorage.setItem(LANG_KEY, code); }catch(e){}
  document.documentElement.lang = code;
  document.documentElement.dir = I18N.meta[code].dir === "rtl" ? "rtl" : "ltr";
  const sel = document.getElementById("lang-select");
  if(sel) sel.value = code;
  await loadOverlay(code);
  relocalizeDecks();
  applyStatic();
  render();
}
function mountLangSelect(){
  const sel = document.getElementById("lang-select");
  sel.innerHTML = Object.keys(I18N.meta).map(c =>
    `<option value="${esc(c)}" ${c === lang ? "selected" : ""}>${esc(I18N.meta[c].name)}</option>`).join("");
  sel.onchange = () => setLang(sel.value);
}
```

```python
# Fields a card may localize vs the ones the games score on. A key in neither
# set is ignored (ids, coordinates, icons...). This is THE policy line — the
# spec's "answers stay English" lives here.
TRANSLATABLE = {"label", "sub", "why", "text", "detail", "prompt", "snippet",
                "tell", "note", "hint", "def", "brief", "scenario", "milestone",
                "definition", "zdef"}

def extract_translatables(data) -> dict:
    """Walk a deck/corpus; return {ancestor_id: {dotted.path: english_text}}.

    Ancestor = nearest enclosing object with an 'id' (cards, pairs, ladders,
    cases, briefs, milestones); an object with 'key'+'def' but no id anchors
    as "zone:<key>". Strings under TRANSLATABLE keys within an ancestor are
    recorded at their dotted path relative to the ancestor.
    """
    out: dict[str, dict[str, str]] = {}
    def walk(node, anchor, path):
        if isinstance(node, list):
            for i, v in enumerate(node):
                walk(v, anchor, f"{path}[{i}]" if path else f"[{i}]")
            return
        if not isinstance(node, dict):
            return
        if node.get("id") is not None:
            anchor, path = str(node["id"]), ""
        elif anchor is None and node.get("key") is not None and node.get("def") is not None:
            anchor, path = f"zone:{node['key']}", ""
        for k, v in node.items():
            sub = f"{path}.{k}" if path else k
            if isinstance(v, str) and k in TRANSLATABLE and anchor is not None:
                out.setdefault(anchor, {})[sub] = v
            else:
                walk(v, anchor, sub)
    walk(data, None, "")
    return out
```
