# AWS architecture icons

These SVGs come from the official AWS Architecture Icons package dated April 30, 2026.

- Source: https://aws.amazon.com/architecture/icons/
- Package: `Icon-package_04302026.zip`
- Retrieved: July 25, 2026

AWS permits customers and partners to use these assets in architecture diagrams and supporting materials such as presentations, data sheets, and posters. The files retain their official package names and artwork.

Some catalogue entries do not have dedicated icons in this release. The game uses an official parent-service or category icon for those entries:

- Strands Agents and Kiro: Artificial Intelligence category
- Amazon Titan and Amazon PartyRock: Amazon Bedrock
- SageMaker AI JumpStart, Studio, HyperPod, and Hugging Face on AWS: Amazon SageMaker AI
- AWS Trainium and AWS Inferentia: AWS Neuron
- Amazon EC2 P5 and G5 instances: Amazon EC2

The product name remains visible and accessible wherever a fallback icon is used.

Capability tokens use official AWS resource icons where the package provides an exact semantic match, including SageMaker models, notebooks, training, and Canvas; Rekognition images; EC2 instances; and EC2 AMIs. All other capability tokens inherit their owning service icon. This avoids using an unrelated service icon as though it represented the capability itself.
