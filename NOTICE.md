# Third-party assets

The `LICENSE` in this repository covers the code, game data and page content
written for this project. It does **not** cover the third-party artwork bundled
under `gamification/assets/`, which stays under its owners' terms. If you fork
this project, those terms bind you directly — not through this repository.

| `gamification/assets/azure-icons/` | Azure Architecture Icons, `Azure_Public_Service_Icons_V24.zip` | https://learn.microsoft.com/en-us/azure/architecture/icons/ — permitted in architectural diagrams, training materials or documentation only; Microsoft reserves all other rights. Each folder's own README records the exact package, retrieval date and quoted
terms. **Keep those READMEs with the files** if you redistribute.

Three consequences worth being explicit about:

- The world map is **CC BY-SA 3.0**, which is share-alike and permits commercial
  use. This project's noncommercial LICENSE cannot and does not restrict it: the
  map artwork stays available to you under CC BY-SA 3.0 on its own terms, and any
  modified map you distribute must stay under CC BY-SA 3.0 with attribution. The
  attribution line is already rendered inside the map games — leave it there.

- Microsoft's terms permit copying and displaying the Azure icons *for the
  permitted use only*. A fork that uses them for something other than diagrams,
  training material or documentation is outside those terms regardless of what
  this project's LICENSE says.
- Vendor names and logos are trademarks. Nothing here grants any trademark
  right, and a fork must not imply endorsement by AWS, Microsoft, OpenAI,
  Anthropic, Perplexity, or the IAPP.
